Project Overview

This project demonstrates a simple static website prepared for deployment using GitHub Pages as a cloud-like hosting platform.

Hosting Platform

Platform: GitHub Pages

Application type: Static HTML website

Deployment: Configured through repository settings

Deployment Steps

  1. Create an HTML website.
  2. Upload the file to a GitHub repository.
  3. Enable GitHub Pages in repository settings.
  4. Choose the deployment branch and folder.
  5. Open the published URL and verify the website.

Cloud Concepts Learned

  • Web hosting and public access
  • Repository-based deployment
  • HTTPS and secure website access
  • Deployment verification and troubleshooting
